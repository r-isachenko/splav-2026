# Сплавные ребята — сайт сплава 2026

Публичная одностраничная страница для участников: нитка маршрута с картой,
тайминги, общее снаряжение, личные вещи и меню. Собирается из заметок сплава
(`01`, `03`, `04`, `05`) скриптом `build.py`. **Траты и логистика из/до Москвы
намеренно не публикуются.**

## Пересобрать после правки заметок

Из корня vault:

```bash
.venv/bin/python "Personal/Сплав 2026/site/build.py"
```

Скрипт заново парсит markdown-заметки и перезаписывает `index.html`.
Зависимостей нет — только стандартная библиотека Python.

## Посмотреть локально

Открыть `index.html` в браузере (карте нужен интернет).

## Ключ Яндекс.Карт

Карта работает на Яндекс.Картах (JS API 2.1) и требует бесплатный ключ.

1. Получить ключ: [developer.tech.yandex.ru](https://developer.tech.yandex.ru/services/) →
   «JavaScript API и HTTP Геокодер».
2. Вписать его в `build.py` → `CONFIG["yandex_api_key"]`.
3. Пересобрать (`deploy.sh` или `build.py`).

Без ключа вместо карты покажется ссылка «Открыть в Яндекс.Картах» (фолбэк).

## Опубликовать на GitHub Pages

Публикуется **только папка `site/`** — это отдельный публичный репозиторий,
не весь vault. Из папки `site/`:

```bash
cd "Personal/Сплав 2026/site"
git init
git add index.html assets README.md build.py
git commit -m "Сплавные ребята: сайт сплава 2026"
gh repo create splav-2026 --public --source=. --push
```

Затем в GitHub: **Settings → Pages → Build and deployment →
Deploy from a branch → `main` / `root`**.

Через ~1 минуту страница будет по адресу
`https://<username>.github.io/splav-2026/`.

## Синхронизация заметок и сайта

Источник истины — заметки в vault; в репозиторий попадает только собранный
`site/`. GitHub Actions пересобирать не может (у него нет доступа к заметкам),
поэтому сборка локальная. После правки любой заметки — одна команда:

```bash
"Personal/Сплав 2026/site/deploy.sh"
```

`deploy.sh` пересобирает `index.html`, и если что-то изменилось — коммитит и
пушит в `origin`. GitHub Pages обновит страницу за ~1 минуту.
`deploy.sh --dry` — пересборка без git (проверить локально).

Страховка: git-хук `pre-commit` пересобирает сайт перед любым коммитом, так что
в репозиторий не попадёт устаревший `index.html`, даже если коммитить вручную.
Хук живёт в `.git/hooks/pre-commit` и не версионируется — на новой машине
скопировать заново.

Автосборка «на сохранение» (по желанию) — если стоит `entr`:

```bash
cd "Personal/Сплав 2026"
ls 0*.md | entr -s '"site/deploy.sh"'
```

## Что где

- `build.py` — сборщик (парсер заметок + шаблон страницы).
- `index.html` — готовая страница (генерируется, её и публикуем).
- `assets/styles.css` — оформление (mobile-first, светлая/тёмная тема).
- `assets/route.js` — карта Яндекс.Карт с метками опорных точек.
- `assets/checklist.js` — галочки в чек-листах (сохраняются в браузере участника).
- `assets/emblem.png` — эмблема (копия `Generated image 1.png`).
