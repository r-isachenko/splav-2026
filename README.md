# Сплавные ребята — сайт сплава 2026

Публичная одностраничная страница для участников: нитка маршрута с картой,
тайминги, общее снаряжение, личные вещи и меню. Собирается из заметок сплава
(`01`, `03`, `04`, `05`) скриптом `build.py`. **Траты и логистика из/до Москвы
намеренно не публикуются.**

## Пересобрать после правки заметок

Из корня vault:

```bash
.venv/bin/python "Personal/Сплав 2026/site/build.py"
```

Скрипт заново парсит markdown-заметки и перезаписывает `index.html`.
Зависимостей нет — только стандартная библиотека Python.

## Посмотреть локально

Открыть `index.html` в браузере (карта и шрифты Leaflet тянутся из интернета).

## Опубликовать на GitHub Pages

Публикуется **только папка `site/`** — это отдельный публичный репозиторий,
не весь vault. Из папки `site/`:

```bash
cd "Personal/Сплав 2026/site"
git init
git add index.html assets README.md build.py
git commit -m "Сплавные ребята: сайт сплава 2026"
gh repo create splav-2026 --public --source=. --push
```

Затем в GitHub: **Settings → Pages → Build and deployment →
Deploy from a branch → `main` / `root`**.

Через ~1 минуту страница будет по адресу
`https://<username>.github.io/splav-2026/`.

При следующих правках: пересобрать `build.py` в vault, скопировать обновлённый
`index.html` в репозиторий (или вести репозиторий прямо в этой папке) и
`git commit && git push`.

## Что где

- `build.py` — сборщик (парсер заметок + шаблон страницы).
- `index.html` — готовая страница (генерируется, её и публикуем).
- `assets/styles.css` — оформление (mobile-first, светлая/тёмная тема).
- `assets/route.js` — карта Leaflet + OSM с маркерами опорных точек.
- `assets/checklist.js` — галочки в чек-листах (сохраняются в браузере участника).
- `assets/emblem.png` — эмблема (копия `Generated image 1.png`).
